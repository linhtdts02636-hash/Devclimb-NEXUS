# Devclimb-NEXUS

Devclimb-NEXUS is a full-stack project with a Spring Boot backend and a Vue 3 + Vite frontend.

## Structure

- `backend/` - Spring Boot application (`com.devclimb`)
- `frontend/` - Vue 3 + Vite application

## Getting started

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
